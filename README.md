Leonida Legend is a fully offline GTA 6 trophy guide and tracker covering all 55 PS5 trophies with an original guide for every trophy, missable warnings, and a seven-stage roadmap to the platinum. Tick trophies off as you earn them, filter by story, missable, collectibles, activities or online, protect yourself with spoiler mode, and export or import your progress — all in a dark neon Vice-styled interface that never touches the network.

## Run it

```sh
node serve.ts
```
Then open http://localhost:8080 in a browser. The guide works fully offline.
